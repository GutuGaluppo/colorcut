# ColorCut brand notes

- Visual direction: Third Exploration.
- Icon: C — Layered Leaf.
- Palette: Fresh & Playful.
- Tone: precise, friendly, confident, calm.
- Interface: neutral off-white foundation, vivid accents only where meaningful.
- Motifs: translucency, layered organic shapes, checkerboard transparency.
- Avoid: heavy shadows, childish illustration, dense chrome, generic editor aesthetics.
